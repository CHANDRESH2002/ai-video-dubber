# Primary translation path (Indic targets, e.g. Hindi) is IndicTrans2 via
# transformers + IndicTransToolkit above — no extra service needed, but the
# model is gated: accept the license at
# https://huggingface.co/ai4bharat/indictrans2-en-indic-dist-200M first.
#
# Non-Indic targets (es, fr, de, ...) fall back to Ollama (not a pip
# package) running locally: `brew install ollama && brew services start
# ollama && ollama pull qwen2.5:7b` — untested since qwen2.5:7b was removed
# from this machine to save memory; measured much lower translation
# quality than IndicTrans2 even for Hindi (see components/translation.py).
#
# unbabel-comet (CometKiwi quality scoring, components/evaluation.py) is
# deliberately NOT listed here -- it hard-conflicts with pyannote.audio
# (pyannote needs torchmetrics>=1.6.1, comet needs torchmetrics<0.11.0,
# no version satisfies both). Not used by the production
# dub_multispeaker.sh pipeline, only by ad-hoc evaluation scripts -- if
# you need those, install unbabel-comet==2.2.7 in a separate venv without
# pyannote.audio. See requirements-eval.txt.
